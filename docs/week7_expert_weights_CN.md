# 专家权重（AHP）到底依据什么判断

## 0. 一句话

权重不是在"测量"什么，而是在**声明一种取舍**。所以它没有唯一正确答案——
但可以做到**有据、可查、可检验**。这份文档就是教你怎么把"我觉得"变成"可论证"。

---

## 1. 三条可以依据的东西（按可靠度从高到低）

### 依据 1：工程约束（最硬，必须优先）

坡度不是可以随便取舍的因子，它是**硬约束**：

* Apollo 登月舱的着陆姿态极限约 12°；现代设计普遍按 10–15° 作为安全上限；
* 巡视器爬坡能力通常 15–20°，超过就无法通行；
* 所以"坡度过大"是**一票否决**，而不是"扣一点分"。

**推论**：坡度应当是权重最高、或至少并列最高的因子。
写论文时请引用具体数值的来源（工程手册/文献），而不是"一般认为"。

### 依据 2：危害的"可探测性与可规避性"

同样危险的两个因素，**能事先测绘并规划规避**的那个，对选址的权重可以低一些：

* **撞击坑**：尺度大（km 级），先测绘就能避开；但落入坑内或坑缘是硬伤；
* **石块**：尺度小（m 级）、分布随机，是着陆器和巡视器最直接的威胁；
* **粗糙度**：它是坡度和石块的**代理变量**，本身不是独立危害。

**推论**：既然已经有独立的坡度层和撞击坑层，粗糙度的**边际信息最少**，
权重可以最低。这一条是可以写进论文论证的。

### 依据 3：你自己数据的可信度

这是最容易被忽略、但对本科生项目最有力的一条依据——因为你**量化过**：

| 因子层 | 我们已知的可信度问题 |
|---|---|
| 撞击坑 | 人工核查：precision ≈ 0.73（0.64–0.81）、可探测召回 ≈ 0.72（0.66–0.79），**不是完美** |
| 粗糙度 | 对阈值极敏感：换分位数标定，安全区从 58 % 变到 78 % |
| 坡度 | 与 NAC 3.28 m 对照过：中低坡度区一致性最好（MAE 4 m 以下） |

**推论**：**可信度低的因子给低权重**——这不是主观，而是有本文档第 5、6 周数据支撑的定量理由。

## 2. 为什么不能直接写 0.5/0.3/0.2

直接填三个数有三个问题：①无法审计（读者不知道你怎么想的）；
②容易受"整数偏好"影响（人人都写 0.5/0.3/0.2）；③无法检验自洽性。

AHP 把"给三个因子配权重"这个大问题拆成 **3 次两两比较**（n=3 时只有 3 对），
每一对只需回答"哪个更重要、重要多少"，并给出**一致性比例 CR** 来检查你的判断有没有自相矛盾。

## 3. Saaty 1–9 标度：用我们的因子把话说清楚

`a_ij = 行因子 比 列因子 重要多少倍`

| 数值 | 含义 | 用"坡度 vs 粗糙度"举例 |
|---|---|---|
| 1 | 同等重要 | 两者对能否安全着陆的影响相当 |
| 3 | 略重要 | 坡度超限直接导致倾覆，粗糙度只是加剧风险 |
| 5 | 明显重要 | 粗糙度在坡度已经合规的地形上基本不构成独立威胁 |
| 7 | 强烈重要 | —— |
| 9 | 极端重要 | —— |
| 2,4,6,8 | 介于两者之间 | 想表达"比略重要再多一点" |
| 1/3, 1/5 … | 反过来 | "粗糙度比坡度次要 3 倍" |

**操作规则**：只需要填**上三角的 3 个格子**，下三角自动填倒数（`a_ji = 1/a_ij`）。
脚本会检查倒数关系，填错会警告。

## 4. 一致性检验（CR）是什么

三个因子只比较 3 次，但你的判断之间可能"绕圈矛盾"：说 A>B、B>C，却又说 C>A。

```text
CI = (lambda_max - n) / (n - 1)              # 偏离完全一致的程度
CR = CI / RI,   RI(n=3) = 0.58               # 随机一致性指标

CR < 0.10  可接受
CR >= 0.10 判断不自洽，需要回头修改比较
```

`lambda_max` 是判断矩阵的最大特征值：完全一致时等于 n（3），偏离越多越大。
我们的脚本用**行几何平均法**求权重（AHP 的标准实用算法），再据此算 CR。

## 5. 一个完整的样例推理（教你怎么想，**不是让你照抄**）

> 前提：载人任务、安全优先、我们的三因子是坡度/粗糙度/撞击坑。

1. **坡度 vs 粗糙度**：坡度直接决定着陆器能否保持姿态；粗糙度在坡度合格的地形上
   很少独立致险 → 坡度**略到中等重要** → 取 **3**。
2. **坡度 vs 撞击坑**：坑可以事先测绘规避，但落在坑缘仍是硬伤，而坡度是逐点的、
   无法靠规划完全规避 → 坡度**略重要** → 取 **2**。
3. **粗糙度 vs 撞击坑**：坑是明确的几何目标，粗糙度是弥散的统计量 → 坑**略重要** → 取 **1/2**。

矩阵与结果：

```text
              slope  rough  crater
slope           1      3      2
roughness      1/3     1     1/2
crater         1/2     2      1

权重：slope 0.5396   roughness 0.1634   crater 0.2970
lambda_max 3.0092 | CI 0.0046 | CR 0.0079  →  可接受
```

把这三个数字代入适宜性模型（`--weights 0.5396,0.1634,0.2970`），
与等权结果对比：安全区 58.4 % → 62.9 %，**而排名第一的候选点没有变**。
这就是"权重重要、但（在这个场景下）不如阈值重要"的定量证据。

## 7. 如果你实在拿不定主意（三条出路）

1. **就用等权**，并明确说明"我们不做主观排序，把判断留给敏感性分析"——这是最保守、也最容易被接受的做法；
2. **用第 5 节的推理**，把每一步的理由写进论文（本文档提供的正是可引用的论证结构）；
3. **最诚实的做法**：承认权重本身不确定，把 AHP 权重作为**中心值**，
   在第 8 周用 Monte Carlo 在其周围扰动（例如 ±30 %），报告候选点排名的稳定性。

第 3 条正是你的创新点（H3）。**你不需要把权重"猜对"，你需要证明"结论对权重不敏感"**——
而第 7 周已经给出了初步证据：换权重，前 10 名候选点重合 9/10；换阈值，只重合 5/10。

作者用 `python scripts/week7_ahp.py --interactive` 完成了三次两两比较：

| 问题 | 回答 | 理由 |

```text
矩阵                权重
      坡    糙    坑       slope      0.5499
坡     1     3     2       roughness  0.2098
糙    1/3    1     1       crater     0.2402
坑    1/2    1     1

lambda_max 3.0183 | CI 0.0091 | CR 0.0157   → 可接受（< 0.1）
```

### 8.1 这个 CR 从哪来的（一个很好的教学例子）

完全自洽的判断应该满足：如果 `坡度/粗糙度 = 3` 且 `坡度/撞击坑 = 2`，
那么 `粗糙度/撞击坑` 应当等于 `2/3 = 0.67`。作者在第 3 题答的是 **1（同等）**，
所以出现了轻微的不一致——**这正是 CR 度量的东西**：不是"你答错了"，
而是"你的三个回答之间有多少循环矛盾"。CR = 0.0157 远小于 0.1，
说明这点矛盾完全可以接受，无需回头修改。

### 8.2 用这套权重跑出来的结果（与等权对比）

| 指标 | 等权 | 作者 AHP |
|---|---|---|
| 权重（坡/糙/坑） | 0.333 / 0.333 / 0.333 | 0.550 / 0.210 / 0.240 |
| 安全区占比 | 58.4 % | **70.7 %** |
| 危险区占比 | 10.5 % | 8.7 % |
| 最优候选点 | (353.76°E, 11.08°N) | **(353.76°E, 11.08°N)**（同一处） |
| 论文 LS3 的分位 | 80.6 % | 82.1 % |
| 论文 LS2 的分位 | 1.3 % | 1.6 % |

**结论没有改变**：换权重只移动了安全区的面积比例（58 %→71 %），
但最优候选点、论文四点的相对排序都保持稳定。这与第 7 周的稳定性分析一致
（权重改变时前 10 名重合 9/10，阈值改变时只重合 5/10）。
