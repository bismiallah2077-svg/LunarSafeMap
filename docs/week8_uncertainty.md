# 第 8 周：不确定性分析（Monte Carlo）

第 7 周每套参数给出一张适宜性图。第 8 周要回答的是另一个问题：
**当我们不再假装参数是已知的，结论还能剩下多少？**

脚本：`scripts/week8_montecarlo.py`（14 项自测）。运行时间 200 次扰动约 3.3 分钟。

---

## 1. 扰动什么、固定什么

| 参数 | 取值 | 依据 |
|---|---|---|
| 因子权重 | Dirichlet(浓度 × AHP 中心)，中心 = 0.550/0.210/0.240 | 第 7 周作者 AHP；Dirichlet 保证均值等于中心且始终在单纯形上 |
| 权重不确定性强度 | 浓度 15（宽）与 60（≈±30 %）两套 | 检验"权重不确定性有多大"本身是否影响结论 |
| 坡度阈值 | 安全 {3, 5, 8}°，危险 {10, 15, 20}° | 工程限制区间 |
| 粗糙度阈值 | 安全 {0.5, 1, 2} m，危险 {3, 5, 10} m | 无量纲、无普适工程限值 → 必须扰动 |
| 坑缘缓冲 | {500, 1000, 2000} m | 着陆安全距离的常见取值 |
| 撞击坑目录 | 632 个（精度导向）或 897 个（召回导向） | 第 6 周人工核查给出的两种口径 |

**固定**：DEM、地形指标、撞击坑轮廓、59.2 m 网格、5 km 站点窗口。
（本周不重训模型；"分辨率效应"需要 NAC，留到 H1 的专门实验。）

> 速度关键：坑缘距离变换只算一次（每个目录一次），每次扰动只是重新缩放，
> 因此 200 次抽样的总耗时是 3 分钟而不是几小时。

---

## 2. 结果一：**安全区面积比例是高度不确定的**

| 运行 | 均值 | 5–95 % 区间 | 最小 – 最大 |
|---|---|---|---|
| 浓度 15（宽） | 0.708 | **0.384 – 0.931** | 0.209 – 0.963 |
| 浓度 60（≈±30 %） | 0.713 | **0.444 – 0.906** | 0.280 – 0.958 |

第 7 周四个确定性取值（等权 0.584 / 熵权 0.756 / 分位数标定 0.784 / AHP 0.707）
全部落在这个区间内——**它们只是这条分布上的四个点，不是四个"结论"**。

**结论**：论文里**不能只报一个"安全区占比"**。诚实的表述是区间，
例如"在 200 次参数扰动下，安全区占研究区面积的 44 %–91 %（5–95 %），均值 71 %"。

---

## 3. 结果二：哪个参数在真正驱动不确定性

按每个参数分组统计平均安全区比例，取组间极差（k = 15 运行）：

| 参数 | 组间极差 | 说明 |
|---|---|---|
| **坡度安全阈值** {3,5,8}° | **0.177** | 最强驱动 |
| **坡度危险阈值** {10,15,20}° | 0.161 | |
| **粗糙度危险阈值** {3,5,10} m | 0.147 | |
| 坑缘缓冲 {500,1000,2000} m | 0.115 | |
| 撞击坑目录（632 vs 897） | **0.034** | 几乎不影响面积统计 |
| 粗糙度安全阈值 {0.5,1,2} m | 0.033 | |

权重的影响（与安全区比例的相关系数）：粗糙度权重 **r = −0.44**（最强，因为是它把地形推入危险类）、
坡度权重 r = +0.25、撞击坑权重 r = +0.14。

两次运行的权重实现范围（论文需如实报告，因为 Dirichlet 的**相对**散布对小权重更大）：

| 因子 | 中心 | 浓度 15 实测 | 浓度 60 实测 |
|---|---|---|---|
| slope | 0.550 | 0.249 – 0.879（0.45–1.60×） | 0.381 – 0.702（0.69–1.28×） |
| roughness | 0.210 | 0.021 – 0.569（0.10–2.71×） | 0.088 – 0.380（0.42–1.81×） |
| crater | 0.240 | 0.017 – 0.604（0.07–2.51×） | 0.116 – 0.442（0.48–1.84×） |

**结论**：占主导的是**阈值选择**，不是权重，也不是撞击坑目录的口径。
这条直接指引用力方向：与其争论权重，不如去论证阈值——而且它也是 H1（分辨率）的入口。

## 4. 结果三：**排名是稳健的**（第 8 周最重要的结论）

每个站点在所有抽样中的排名分位（100 = 全场景最安全窗口）：

| 站点 | 浓度 15：均值 [5–95 %] | 浓度 60：均值 [5–95 %] |
|---|---|---|
| 我们的最优区（353.76°E, 11.08°N） | **100.0 [100, 100]** | 同 |
| 第 7 周前 10 名（西部簇） | 99.3 – 99.9，P(前 10 %) = 1.00 | 同 |
| **论文 LS3** | **83.1 [79.2, 88.2]** | **82.9 [79.8, 87.1]** |
| 论文 Fresh_crater | 70.0 [48.1, 81.2] | 71.4 [56.9, 80.7] |
| 论文 LS1 | 55.9 [35.9, 70.4] | 57.2 [40.9, 68.9] |
| 论文 LS4 | 44.0 [34.8, 54.4] | 44.3 [37.0, 52.6] |
| **论文 LS2** | **2.0 [0.9, 4.3]** | **1.9 [1.1, 3.5]** |
| Bode_C（地标=坑） | 0.0 [0, 0] | 0.0 [0, 0] |

**结论**：面积比例不确定到 ±30 个百分点，但**相对排序几乎不受影响**：
LS3 在 200 次抽样中始终是论文四点里最好的（5 % 分位仍有 79 %），
LS2 始终是最差的（95 % 分位只有 4 %）。

这正好回答了核心科学问题的那一半：**"不同权重和阈值下评价结果是否稳定"**——
答案是"**面积不稳定、排序稳定**"。论文里必须把这两件事分开写。

## 5. 结果四：哪些区域是"参数敏感区"

逐像元统计 200 次抽样中被判为安全的频率：

| 类别 | 面积占比 |
|---|---|
| P(安全) = 1.0（**任何参数下都安全**） | **26.1 %** |
| 0.1 < P(安全) < 0.9（**结论取决于参数**） | **35.2 %** |
| P(安全) = 0.0（任何参数下都不安全） | 6.3 % |
| P(危险) > 0.5 | 8.7 % |

(100 − 26.1 − 35.2 − 6.3 = 32.4 % 为"高度一致的安全"，即 P ≥ 0.9 但非必然。)

**结论**：只有 **26 %** 的研究区在**任何**参数组合下都安全；
**35 %** 的区域"安全不安全"完全取决于你怎么设参数。
这张概率图（`mc_prob_safe.tif` / `mc_prob_danger.tif`）是第 9 周讨论的现成素材，
也是给后续任务规划者的实用产品：**先看那 26 %，别浪费时间去争论那 35 %**。

## 6. 与三个假设的对应

| 假设 | 第 8 周的结论 |
|---|---|
| **H1 分辨率效应**（低分辨率高估安全区） | **本周未检验**（需要 NAC 3.28 m 与 SLDEM 同区域对照；且目前最优候选点与 NAC 条带 0 重叠） |
| **H2 多源融合效应** | 部分支持：第 6 周消融显示山体阴影通道把检测 F1 从 0.460 提到 0.548；第 7 周显示三因子排序对权重不敏感 |
| **H3 评价不确定性** | **直接量化**：面积比例 ±30 个百分点；排序稳健；主导不确定性来自阈值而非权重 |

## 7. 复现命令

